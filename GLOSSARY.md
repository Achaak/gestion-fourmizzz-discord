# Glossaire

Vocabulaire du bot. Le vocabulaire du jeu lui-même (TDC, ponte, grenier…) est dans `docs/fourmizzz/glossaire-du-jeu.md`.

| Terme                     | Dans le code                    | Définition                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Demande**               | `ConvoyRequest`                 | Ce qu'un membre demande à recevoir en convoi pour une construction ou une recherche : nourriture et/ou matériaux, niveau visé, date souhaitée. Numérotée (n° 1, 2…).                                                                                                                                                                                                                                                           |
| **Demandeur**             | `requester`                     | Le membre qui a fait la demande et qui reçoit les convois.                                                                                                                                                                                                                                                                                                                                                                     |
| **Responsable (convois)** | `isManager`, `validatedBy`      | Membre qui peut valider une demande et annuler celle des autres. Aujourd'hui : permission Discord « Gérer les messages ».                                                                                                                                                                                                                                                                                                      |
| **En attente**            | `status: "pending"`             | Demande faite, pas encore validée. On ne peut pas encore la livrer.                                                                                                                                                                                                                                                                                                                                                            |
| **Validation**            | `validateRequest`               | Un responsable accepte la demande ; elle passe **en cours**. C'est là que l'alliance priorise.                                                                                                                                                                                                                                                                                                                                 |
| **En cours**              | `status: "active"`              | Demande ouverte aux livraisons.                                                                                                                                                                                                                                                                                                                                                                                                |
| **Livraison**             | `Delivery`                      | Un convoi envoyé pour une demande, **déclaré** par celui qui l'envoie (en postant les lignes du jeu dans le salon des convois, ou avec `/livrer`). Le bot ne vérifie pas dans le jeu. Compte dans le reste dès sa déclaration, même s'il n'est pas encore arrivé. Une ligne déjà déclarée par le même membre (mêmes quantités, arrivée à 2 min près) est ignorée : poster puis recoller la même ligne ne compte pas deux fois. |
| **Arrivée**               | `Delivery.arrivesAt`            | Quand le convoi atteint le demandeur, lue dans la ligne du jeu. Avant, la livraison est **en route** et le tableau la montre sous la demande.                                                                                                                                                                                                                                                                                  |
| **Livreur**               | `Delivery.by`                   | Le membre qui a envoyé une livraison.                                                                                                                                                                                                                                                                                                                                                                                          |
| **Reste**                 | `remaining`                     | Ce qu'il manque encore, ressource par ressource. Un surplus de nourriture ne compense pas des matériaux manquants.                                                                                                                                                                                                                                                                                                             |
| **Avancement**            | `progress`                      | Part livrée de la demande, de 0 à 100 %, calculée sur le reste.                                                                                                                                                                                                                                                                                                                                                                |
| **Terminée**              | `status: "done"`                | Plus rien ne reste : la demande se ferme d'elle-même à la livraison qui la complète.                                                                                                                                                                                                                                                                                                                                           |
| **Annulée**               | `status: "cancelled"`           | Fermée par le demandeur ou un responsable. N'apparaît plus dans le tableau.                                                                                                                                                                                                                                                                                                                                                    |
| **Tableau (des convois)** | `renderBoard`, `BoardPublisher` | L'unique message permanent du salon des convois : demandes en cours (avec les convois en route), en attente, terminées sur 7 jours. Modifié après chaque changement, jamais reposté.                                                                                                                                                                                                                                           |
| **Membre**                | `Member`                        | Un joueur de l'alliance vu par Discord : identifiant Discord et nom affiché sur le serveur (normalement son pseudo du jeu). Le lien vers le compte du jeu viendra de l'API (`docs/projet/architecture.md`).                                                                                                                                                                                                                    |

## À éviter

- « Commande » pour une demande : réservé aux commandes slash de Discord.
- « Convoi » pour une demande : un convoi est un envoi dans le jeu ; une demande en reçoit plusieurs (ses livraisons).
